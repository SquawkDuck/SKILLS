# SKILLS

Shared Codex skills repository.

## Skills

- `hit-me-plan`: starts with `hit me`, builds a root `plan.MD` one question at a time, then finalizes the plan when enough information has been gathered.

## Install on another machine

Clone this repository or copy individual skill folders into your Codex skills directory:

```bash
git clone https://github.com/SquawkDuck/SKILLS.git ~/codex-skills
mkdir -p ~/.codex/skills
cp -R ~/codex-skills/hit-me-plan ~/.codex/skills/
```

Do not store secrets, API keys, tokens, or private customer data in this repository.
